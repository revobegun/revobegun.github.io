<p class="lede">
Same three steps on every device: install Hiddify, import your config, tap
connect. Pick your device below.
</p>

<h2>Android</h2>

<ol class="steps">
<li>Go to <a href="https://hiddify.com">hiddify.com</a> and download the APK.</li>
<li>Open the file. Allow install when Android asks.</li>
<li>Open Hiddify. Tap <strong>+</strong> at the top.</li>
<li>Scan your QR code, or paste your config link.</li>
<li>Tap the profile, then tap connect.</li>
</ol>

<h2>iPhone / iPad</h2>

<p>Your Apple ID needs to be set to a region outside mainland China for this.</p>

<ol class="steps">
<li>Search the App Store for <strong>Hiddify Next</strong>. Install it.</li>
<li>Open it. Tap <strong>+</strong>.</li>
<li>Scan your QR code, or paste your config link.</li>
<li>Tap the profile, then tap connect.</li>
<li>iOS will ask to add a VPN. Approve it.</li>
</ol>

<h2>Windows</h2>

<ol class="steps">
<li>Download Hiddify for Windows from <a href="https://hiddify.com">hiddify.com</a>.</li>
<li>Run the installer. If SmartScreen warns, click <strong>More info → Run anyway</strong>.</li>
<li>Open Hiddify. Click <strong>Add Profile</strong>.</li>
<li>Paste your config link.</li>
<li>Click the profile, then click connect.</li>
</ol>

<h2>Mac</h2>

<ol class="steps">
<li>Download the Mac version from <a href="https://hiddify.com">hiddify.com</a>.</li>
<li>Drag Hiddify into Applications.</li>
<li>First time only: right-click the app, choose <strong>Open</strong>, confirm.</li>
<li>Click <strong>Add Profile</strong>, paste your config.</li>
<li>Click the profile, then connect.</li>
</ol>

<h2>Did it work?</h2>

<p>Visit <a href="https://ifconfig.me">ifconfig.me</a>. The IP shown should
<em>not</em> be from your country. If it is, the VPN isn't actually on — check
that the app says "connected."</p>
