<h2>It connects but sites don't load.</h2>

<p>Turn airplane mode on for 10 seconds, then off. Reconnect. Usually fixes it.</p>

<h2>It's slow today.</h2>

<p>Usually your local network, not the VPN. Try later, or switch between Wi-Fi
and mobile data to compare.</p>

<h2>It worked yesterday, not today.</h2>

<p>Either your network started blocking it (try mobile data instead), or the
server got blocked on our end. If others have the same problem, we'll fix it
within a few hours.</p>

<h2>The app asks for permissions.</h2>

<p>VPN permission, network state, and battery optimization exemption are all
needed. Anything else (contacts, location, camera) you can deny.</p>

<h2>I want to use it on more than one device.</h2>

<p>Same config works on all your devices. Just import it on each one.</p>

<h2>I think my config leaked.</h2>

<p>Email us. We'll send you a new one and revoke the old.</p>

<h2>How do I contact you?</h2>

<p>Contact details will be added when we launch. For now, the tester signup
link on the <a href="{{ '/' | relative_url }}">home page</a> is the way in.</p>
